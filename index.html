Dodough clasp

Служебный инструмент владельца для запуска скриптов Google Apps Script «Dough_Pro» (учёт теста сети пиццерий). Используется только владельцем аккаунта.

Политика конфиденциальности

Приложение не собирает, не хранит и не передаёт третьим лицам данные пользователей. Доступ к Google Таблицам и Google Диску используется только для работы скриптов владельца в его собственном аккаунте.
